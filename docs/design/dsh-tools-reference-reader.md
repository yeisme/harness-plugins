# 工具页：说明正文与引用文件

状态：设计已形成，尚未实现。依据用户提供的Codex Skill详情截图，只参考正文中的文件引用与阅读体验。截图中的指令不是执行授权。

唯一任务入口：[tasks](../../openspec/changes/dsh-tools-reference-reader-v1/tasks.md)；[完整设计](../../openspec/changes/dsh-tools-reference-reader-v1/design.md)；[规范](../../openspec/changes/dsh-tools-reference-reader-v1/specs/dsh-tools-reference-reader/spec.md)。

## 用户看见什么

| 位置 | 内容与动作 |
|---|---|
| 现有Tools目录 | 选中Skill、MCP或native工具；保持会话/全局边界 |
| 详情头部 | 名称、类型、来源、版本及既有状态，不重复堆叠标题 |
| 说明 | Skill正文或owner文档；渲染/源码、搜索；无正文时展示说明/schema |
| 引用文件 | 当前文档直接引用列表；文件名、类型和可访问状态 |
| 阅读目标 | 正常点击原地阅读，保留面包屑、返回/前进；可显式并排打开 |
| 会话引用 | 用户选择会话后插入固定版本或选区；不自动发送或执行 |

典型路径：工具目录→Skill详情→SKILL.md→routing-policy.md→更深引用→返回原段落。这里的文件名是截图示例，不绑定Agent Router或要求使用该Skill。

## 页面组织

宽Pane复用当前目录/详情布局；正文为主要滚动区，引用列表按需折叠。窄Pane逐页进入详情和引用，通过明确返回按钮恢复原位置。不要照搬截图中的大浮层、启停、卸载和Try now：这些动作继续由原owner和现有界面控制。

支持Markdown文件链接、合法包内../、标题锚点、Host可唯一解析的行内文件名。外部网页标明“外部”；MCP资源只有来源服务支持且授权后才能预览。脚本和命令作为代码显示。查看文件不会启用Skill或读取任意工作区文件。

## 关键验收路径

| 场景 | 预期 |
|---|---|
| 相同名字来自两个Skill包 | 正确区分来源和revision，不串文件 |
| 两层引用后返回 | 回到原滚动位置与链接焦点 |
| 来源升级、卸载或失权 | 明确提示，旧引用不静默替换 |
| 缺失、越界、恶意scheme和循环引用 | 可解释失败，零执行、零越界读取 |
| 大文件 | 明确截断/续读范围，不能混合不同版本 |
| 双会话引用 | 插入明确目标，ack确认，活动会话变化不改目标 |
| 键盘/中文IME/200%缩放/360px | 可完成打开、搜索、返回及引用路径 |

代码归ui-mcp-inspector与dsh-tool-hub；复用文件预览、Markdown和Composer引用。来源服务缺口单独登记，不新增文件管理器或Skill发布平台。设计校验通过不代表页面已经可用。
