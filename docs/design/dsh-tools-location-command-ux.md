## 截图反映的问题

1. 定位原消息之后没有醒目的记录标记，用户无法确认跳到了哪条调用。
2. 详情只展示bash/edit/read，缺少实际命令或目标操作的安全摘要。
3. 标题被统计和操作按钮挤碎，重新检测被挤到下一整行；工具名局部灰色选择难以辨识，详情空白过多。

## 约定方向

- 定位后的反馈包含正确会话/Tab、活动Pane边界和原调用持续高亮；按调用引用定位，不能按同名工具猜测。
- 调用详情展示所属owner提供的命令/操作摘要。命令先脱敏再截断；复杂脚本和无法安全判定的参数不直接展示。缺摘要时明确说明，不伪造原命令。
- 操作摘要与完整原始参数是不同产品能力；本次不增加执行、重试或完整参数导出。
- 采用现有Pane的紧凑字体、按钮、间距、圆角和accent，整行选中，标题保持可读。列表/时间线语义保持，详情随选择呈现。
- 主线程的会话Tools Tab、固定旁栏和会话管理方案继续有效；本补充不替代其实现和验收。
