# DSH 搜索中心：从分类探索到资源打开

本页说明搜索中心 v2 的目标体验，目前已进入实施阶段：分类探索、快捷视图、范围选择、查询交接、只读元数据预览及来源调度已形成本地实现；已安装Skills／原生工具已接原Tools目录与详情，文件／目录名称已接原文件owner分页，正文、会话目录和其他owner仍在推进，尚未完成运行宿主验收。完整决策、分类账本和线框以 [design.md](../../openspec/changes/dsh-search-center-v2/design.md) 为准；[规范](../../openspec/changes/dsh-search-center-v2/specs/dsh-search-center/spec.md)定义验收行为，[任务](../../openspec/changes/dsh-search-center-v2/tasks.md)和[实施记录](../../openspec/changes/dsh-search-center-v2/implementation-baseline.md)跟踪证据与剩余工作。

## 两个入口，同一份搜索

搜索中心是可以持续浏览的 Pane；快捷浮层帮助快速查找并打开资源。已实现的浮层“在搜索中心继续”路径会保留输入、范围、筛选和选中项，复用已打开的搜索中心。

浮层会等待搜索中心接收上下文后再关闭。目标未能接收时，3秒后显示失败提示，输入与选择留在浮层，可继续编辑或重试；等待期间修改查询、范围或筛选会取消这次交接。原选中资源尚未返回时不会自动打开其他结果。

在输入框用上下键选择结果，按 Shift+F10 打开操作菜单，也可以 Tab 到“选中结果的操作”。菜单上下键跳过不可用操作，Home／End到首末项，Escape返回搜索输入框；左右键仍用于编辑查询。打开菜单不会执行工具或命令。

快捷浮层内的 Tab／Shift+Tab 会在当前可用控件间循环，进入预览后跳过已隐藏的结果。搜索中心 Pane 保持自然 Tab 顺序，可以移动到相邻 Pane。触控设备上的搜索按钮、输入框、选择器及操作菜单提供至少44px触控尺寸。

窗格宽度不超过420px时，通过“浏览分类”和“搜索筛选”打开面板，搜索范围仍显示在主界面。面板中的条件直接生效；选择二级分类后返回结果，也可以按“完成”保留当前选择。窗格变宽后恢复对应布局，查询和条件不丢失。软键盘收缩可视区域或窗口高度较小时，搜索自身可滚动，底部动作仍可到达；恢复后保留查询和条件。

既有 `/search` 入口继续使用，不要求记忆新快捷键。当前已经有会话／窗格／命令搜索基础；会话快照的标题／ID匹配不代表能够搜索全部消息、归档或所有项目正文。旧交付情况见 [工作区搜索记录](../delivery/dsh-workspace-search-experience-2026-09-06.md)，不能据此判断 v2 已可用。

## 不知道搜什么时，先看分类

空查询页面左侧提供分类，右侧展示最近访问、已打开、常用入口和分类导航卡片。没有使用记录时直接展示分类，不伪造热门资源。输入关键词后，内容区切换为分组结果列表。

| 分类 | 可以发现的内容（接入目标） |
|---|---|
| 会话与历史 | 会话、消息命中、归档会话 |
| 项目与工作区 | 项目、工作区、画布与节点 |
| 文件与知识 | 文件、文件夹、文档、笔记、知识条目 |
| 素材与成果 | 图片、视频、音频、字幕、文本成果、交付包 |
| 提示词与模板 | 提示词、模板、可复用引用 |
| 工具与能力 | Skills、MCP工具与资源、原生工具、插件、预设 |
| 任务与执行 | 任务、运行、审批、验证、证据 |
| 窗格与操作 | 窗格、命令、设置、兼容与高级入口 |

分类最多两层。“最近、常用、已打开”是快捷视图，项目和来源通过筛选选择。某来源还没接入时会显示“待接入”；已接入来源的失败会显示原因和恢复入口，不会悄悄变成零结果。

## 查找、预览与继续工作

1. **确认范围**：有明确项目时先查该项目，否则显示“所有可访问项目”。每个结果组会说明实际覆盖的是名称与说明、会话目录还是正文。原会话目录可用时，也可明确选择一个会话；清空查询和筛选不会扩大范围。会话被移除后保留所选项并提示不可用。会话工具目录要求宿主提供范围确认，旧宿主缺少该合同时显示来源不可用。
2. **输入或选分类**：支持中文、英文、名称、ID和别名。默认每组最多展示5项，“查看全部”进入该分类；数量不完整时写“已找到”，不冒充总量。
3. **按能力筛选**：项目、来源、时间、标签、类型等条件只在来源支持时生效；不能筛选的来源会说明限制。插件已安装与当前会话能调用是两种不同状态。
4. **查看预览**：结果默认是紧凑列表，媒体分类可主动切换缩略图。宽屏预览显示在右侧，窄屏进入详情并能返回原位置；正文读取、媒体播放均需显式操作。
5. **打开原资源**：已有Pane优先定位，支持时可右侧／下方／悬浮打开。Skill进入Tools详情，文件进入Reader，任务进入原owner。来源未提供某种打开方式时会说明原因。
6. **引用到会话**：只有资源支持时才显示相关动作，先明确目标会话和资源版本，确认插入结果；不会自动发送。切换活动会话不改变已选引用目标。

当前可筛选的会话元数据来自当前profile的会话列表快照，时间和运行状态在该快照分页之前过滤；这不代表已搜索全部历史正文或归档。未知远程来源不支持的条件会明确说明。手动选择的项目不会因邻Pane切换而改变，清除筛选也保留范围；所选项目失去访问权限后保留失效标识并清除其结果。新增高级条件尚未接入偏好保存，当前会显示不可保存的原因。

选择结果或阅读说明不会执行其中的命令、启用Skill、批准任务或应用预设。工具与领域业务仍由原owner管理，搜索中心不创建另一份状态。

## 风格与小屏体验

沿用DSH深浅主题与语义图标。探索卡片帮助选择类别，具体结果保持可扫描的行；没有大块统计、品牌图标墙或装饰性背景。分类栏192px、预览栏320px；只有足够宽的容器才显示三栏。

在窄Pane中，分类改为选择器，预览变为可返回的详情页。键盘可以完成搜索、分类、筛选、预览、打开和返回；触控操作不依赖悬停。200%缩放、软键盘与长中英文标题均纳入后续验收。

## 什么会先交付

- A：统一探索页、现有会话／窗格／命令来源、快捷浮层与中心交接、键盘和异常恢复。
- B：分来源接入Skills／工具、项目文件、知识、素材成果、提示词模板以及Ordo元数据。
- C：只接入已有明确授权与索引合同的正文搜索，验证历史消息定位、版本与范围。

每类来源单独验证；“已有列表接口”“设计完成”“mock通过”都不能代替真实搜索验收。详细接入状态只在完整设计账本与任务中维护，避免多份进度相互矛盾。

在本项目目录执行设计校验：

```bash
openspec validate dsh-search-center-v2 --strict --no-interactive
```

该命令校验规格结构，不验证页面运行效果。后续测试场景和现有测试入口见完整设计的“场景与验收矩阵”。

## 已安装工具目录的当前边界

已安装Skills与原生工具从原Tools owner读取名称、ID、说明和来源，属于目录搜索。它们目前只支持profile范围；选择具体项目时会说明范围不支持，可由使用者显式调整范围。完整目录支持状态筛选和名称排序；目录不完整时显示部分结果。

工具被禁用不妨碍阅读原详情。搜索中的打开不会替使用者启用、安装或执行工具；原owner不能唯一定位的同名来源会标为暂不可打开详情。版本显示 `catalog:` 前缀时代表目录版本，不能据此认定Skill正文已固定版本。

已安装Skill的原Tools详情已提供“阅读正文”。具备owner文件读取合同时，可查看版本固定的源码分段、上一段和下一段；选择条目不会自动加载。正文内的HTML、图片和链接作为文本显示，不会执行或访问。关闭、返回目录或读取被拒绝会清除正文，版本变化后需要显式重新读取。

当前staging尚未应用getDocument owner增量，会明确提示Reader不可用。会话内可调用目录、单个MCP工具、MCP资源及完整引用Reader仍待接入。已有测试使用真实Tools／Host实现和受控目录／正文数据，已部署宿主的完整可用性仍需独立验收。

读屏状态提示会合并短时间内的结果更新，只报告当前显示数量和选中项失效，不逐字播报查询或资源内容。输入法组合输入期间暂停提示。搜索框保留一个“清除搜索”动作，清除后焦点留在输入框。

文件搜索目前按名称匹配，可继续加载 owner 的后续页；不会把当前文件 owner 当成所有项目的全量文件库。文件可交给原文件窗格打开；支持定位合同的宿主会在原Explorer中选中目录，确认后才关闭快捷搜索。Explorer有未完成操作草稿时保留草稿并拒绝切换；不支持该合同的宿主仍只显示目录元数据。项目引用无法与文件 owner 对齐时会拒绝该组，不自动改查其他项目。
