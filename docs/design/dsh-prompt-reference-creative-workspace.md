# DSH 提示词引用与创作工作台

状态：方案和文档已确认，代码实施中，功能尚未验收。所属变更：[dsh-prompt-reference-creative-workspace-v1](../../openspec/changes/dsh-prompt-reference-creative-workspace-v1/proposal.md)；[技术设计与 UI Contract](../../openspec/changes/dsh-prompt-reference-creative-workspace-v1/design.md)；[实施任务](../../openspec/changes/dsh-prompt-reference-creative-workspace-v1/tasks.md)。

本轮面向 DSH 插件与宿主，不涉及 Aigora。现有主题和原子组件以 [DSH 面板统一视觉系统](dsh-unified-panel-visual-system.md) 为唯一依据；旧引用接入继续见 [引用动作与宿主题接入](dsh-reference-theme-integration.md)。以下为产品设计，不宣称现有运行版已经具备全部能力。

## 1. 已确认的体验原则

引用就是加入本轮提示词的一段内容。客户端将它显示为可阅读的引用块，源码、显示和发送预览读取同一份草稿。插入时固定内容，可以改写；编辑引用不改源文件，不需要先建立成果候选或进行版本采纳。

默认输入框紧凑，长文按需展开。引用默认展示来源标题和三行内容；编辑时原位切换源码，完成后恢复展示。发送预览按需打开，异常引用主动指出。来源更新不自动替换，刷新前比较草稿差异。

完整创作能力位于侧边成果面板：工程和媒体成果同等纳入；文档代码直接编辑，媒体标注及基础裁剪，进一步修改交给 Agent。修改先成为候选，明确采纳；采纳与源文件写回分开。网页连接工作区开发／测试服务，不扩展到生产环境。

## 2. 输入框与预览线框

### 默认输入框

```text
当前对话：实现搜索功能                 切换
┌──────────────────────────────────────┐
│ 请检查下面这段代码的边界条件：        │
│ ┌ 文件 · search.ts · L12–18 ────────┐ │
│ │ export function search(query) {  │ │
│ │   …                             │ │
│ │ }                               │ │
│ │ 展开  编辑  查看来源  更多        │ │
│ └─────────────────────────────────┘ │
│ 然后给出修改建议。                    │
├──────────────────────────────────────┤
│ ＋添加  引用 2／全部折叠  预览  发送  │
└──────────────────────────────────────┘
```

目标位置示意可由宿主已有会话标题承担，不再添加重复 Target。工具设置沿用原输入框，在窄屏移入现有菜单；发送与主要编辑动作保持可访问。引用块是整体可操作内容，使用一层轻背景容器，不叠加装饰卡片或阴影。

### 展开输入与原位编辑

```text
当前对话                         收起输入
┌──────────────────────────────────────┐
│ 普通正文……                          │
│ 文件 · search.ts · 已编辑             │
│ [ 原位源码编辑区：Markdown / code ]   │
│ 完成编辑                             │
│ 后续正文……                          │
│                                      │
├──────────────────────────────────────┤
│ 添加  引用清单  发送预览       发送    │
└──────────────────────────────────────┘
```

展开只改变宿主输入区域大小，同一草稿和撤销历史不变。源码编辑不自动格式化；Escape 退出编辑视图并保留输入，撤销负责取消编辑。中文输入法合成中不触发发送或引用候选确认。

### 发送预览

```text
本轮发送预览                       关闭
目标：实现搜索功能
正文与引用：显示实际拼装的 Markdown
附件：实际图片区域／音视频时间段
能力：所选 Agent／技能／工具及本轮用途
问题：如有，定位到引用并提供修复入口
```

预览覆盖用户可控制的本轮内容，不展示隐藏系统指令。源正文变动时同步更新；发送冻结当前 revision 对应内容。超限不能一边显示完整预览一边静默截断发送。普通 @、标题或 HTML 文本不自动变成工具执行或宿主可运行页面。

### 侧边成果面板

```text
┌ 主对话／紧凑输入框 ────┬ 成果：搜索示例 ─────────┐
│ 消息与引用              │ 候选 v3 · 尚未采纳      │
│                        │ 预览 / 源码 / 比较      │
│                        │ [当前成果内容]          │
│                        │ 标注 / 再次引用 / 采纳  │
│ [输入框]               │ 更多：写回来源、放大    │
└────────────────────────┴────────────────────────┘
```

“写回来源”作用于明确的已采纳成果版本，并展示目标和差异。窄屏使用“对话／成果”视图切换，恢复草稿和阅读位置；不将右栏压缩成不可操作的窄列。布局依据容器：<=420px 紧凑，421–720px 单栏默认，>720px 由 Host 在足够宽时提供双栏，否则继续切换视图。两列均需至少 360px 内容宽度及宿主间隔。

## 3. 内容示例与语义

以下均为合成示例，不含真实提示词、路径、凭据或私有资源。标题为人可读描述，实际资源身份与权限来自独立的安全来源信息。引用正文被改写后必须标记已编辑，不能当作原文证据。

### 文件／选区

````markdown
#### 引用：search.ts · 第 12–18 行
```ts
export function normalizeQuery(query: string) {
  return query.trim();
}
```
````

正文可原位修改；模板遇到自身包含代码围栏时使用足够长的外层围栏。显示和源码切换本身不重写正文。普通用户手输相同 Markdown 仍是普通文本，只有显式插入产生引用外观及实例操作。

### 图片区域

```markdown
#### 引用：布局草图 · 选区 A
区域：图片左上角的导航区域。
请对齐图标和标签的间距。
```

同时携带授权图片区域资源与坐标。引用块展示实际区域缩略图，不能仅发送这段描述却宣称模型已看到图片。修改描述不更改区域；调整区域是显式范围编辑并更新对应预览和附件。

### 音视频时间段

```markdown
#### 引用：演示片段 · 00:12–00:19
关注这一段的字幕与旁白衔接。
```

同时携带实际授权片段或可解析媒体与时间范围，播放器从选定范围预览；无法提供范围时明确提示，不擅自发送完整媒体。

### 能力引用

```markdown
#### 本轮技能：代码评审
用途：检查边界条件与回归风险。
```

能力由既有技能／Agent／工具机制解析。展示标题和提示词可以编辑，但不能因此修改底层权限、选择另一个能力或触发执行。需要变更能力对象时重新选择；提及、打开预览和添加标注均不执行工具。

## 4. 两条主要用户流程

### 发现 → 插入 → 编辑 → 预览 → 发送

1. 在输入框用 @ 分组发现，或从文件、消息、终端、媒体面板选择内容。
2. 添加到明确目标和保存光标，无有效光标追加末尾；批量确认绑定目标。
3. 用户留在来源位置，看到添加回执；需要时跳转输入框。
4. 引用默认三行，可折叠为标签或原位编辑。重复引用正文独立，媒体附件按版本和范围去重。
5. 按需查看实际发送内容；修复超限、权限或不可解析附件。
6. 提交确认后只消费本次提交内容。生成中添加进入下一条草稿；发送等待期间修改同一引用或追加文字均保留。

### 成果 → 编辑／标注 → 候选 → 采纳 → 再次引用

1. 打开侧边成果，选择文档、代码、图表、网页或媒体。
2. 工程成果可直接编辑；媒体支持标注与基础裁剪。用户显式提交后进入既有修改流程。
3. 编辑草稿由 owner 提供自动保存能力；缺失时明确本次会话临时状态，并保护离开时的未保存内容。
4. owner 返回候选；文本 diff、图像并排／切换、音视频对应片段切换用于比较。
5. 用户明确采纳，成功回执后更新已采纳版本；源文件保持不变。
6. 需要时独立写回来源，核对目标、差异和源版本。也可以将所选版本或片段再次加入输入草稿。

## 5. 状态与恢复

| 情况 | 呈现与恢复 |
|---|---|
| 加载／空结果 | 保留目标、查询与已有安全内容，说明当前检索范围，不以空白代替无权限 |
| 目标关闭 | 拒绝插入，保留待加入内容并重新选择，不追随最近焦点 |
| 来源更新 | 保留固定草稿，显式刷新并比较；刷新等待中继续编辑则重新比较 |
| 来源删除／权限撤销 | 区分不可定位与无权继续使用；旧快照可否发送由实际授权决定，不自动文本化绕过 |
| 媒体超限／失效 | 指出附件及范围，要求缩小、重新选择或移除；不静默替换或删减 |
| 发送失败／未知 | 保留草稿；未知状态沿原请求对账，不换身份自动重发 |
| 候选保存／采纳未知 | 保留编辑和原动作身份，显示 owner 状态，不假称保存或采纳成功 |
| 写回冲突 | 原文件未覆盖，保留候选，重新读取授权源版本并比较 |
| 开发服务未启动 | 提供 owner 显式启动动作；打开预览不执行命令 |
| 开发页面断连 | 保留成果与草稿，重新读取环境状态；不重放启动或页面业务请求 |
| 缺少嵌入支持 | 显示限制，允许 owner 授权的外部页面入口，内嵌验收仍待完成 |

运行页面使用宿主支持的独立容器和 origin，持续显示开发／测试环境及安全身份提示；不把 HTML 直接注入宿主执行，不绕过应用嵌入限制，不复制宿主认证材料。

## 6. 兼容与职责

新模式明确协商“正文可编辑、投影为提示词”；既有 V1 和 owner 结构化引用继续保持原语义。新模式不是旧模式失败时的自动 fallback。关闭能力后保留新草稿和历史，不强制将其改解释为旧模式。

Conversation 拥有草稿、光标、发送和历史；来源 owner 拥有授权和内容范围；成果 owner 拥有保存、候选、比较、采纳与写回；环境 owner 拥有运行状态与启动。插件提供 UI 和安全投影，不创建领域账本或第二个输入框。

## 8. 验收层级与文档交付

插件协议门与实际 Host 运行分开记录，不能用 mock、编译或历史截图宣称本轮产品完整可用。宿主 seam 通过 upstream-prs 交付，候选／环境 owner 缺口单独登记。用户要求的完整创作工作台仍需要真实 Web 中工程与媒体全流程证据。

未来实现执行 typecheck、test、build、check:bundles、check:surfaces、test:visual、check:plugins 七门及 OpenSpec 严格校验；集成证据写入本仓库 temp/integration-test-runs/<run-id>/，包含 summary.json、command.txt、stdout.log、stderr.log、env.json 和 artifacts/，使用合成数据，脱敏秘密、真实提示词、provider payload、私有参数和绝对路径。

本次文档交付只验证变更完整性、Requirement／Task 一致性和链接有效性，不运行产品服务或勾选功能任务。精确校验结果见所属变更 verification.md。


### 图片成果接入约定（Host-only）

成果 owner 为支持引用的图片提供 `readArtifactImage(artifact, context, signal)`，返回选定 ArtifactRef、contentRevision、PNG／JPEG／WebP／GIF MIME 与有界 Uint8Array；对应 `referenceProof` 的 digest 是完整资源 SHA-256，contentRevision 与读取结果一致。旧 adapter 可继续只提供预览，但不能凭预览 URL 宣称支持发送附件。该读取不加入浏览器 Remote，也不把字节写入 snapshot 或日志。

全图使用 `image` 证明，不附隐藏区域；框选使用 `image-region` 证明和归一化矩形。仅有全图证明时，框选后的“加入主对话”明确禁用，恢复全图后可用。Host 校验授权、版本与内容后，调用既有附件服务做格式校验、实际裁剪和存储。选择模式禁用图片原生拖拽，并捕获指针，避免用户拖动后范围仍停留在全图。

本轮真实 Host 已用合成 owner 验证 726px 原图裁成 364px 附件并发送到 keyless 模型回放；这证明插件／Host 链路，尚不证明真实领域服务或音视频模型接收能力。详情与失败记录见所属 change 的 verification.md。


### HTML 预览与源码切换

HTML 成果默认显示静态结构，可查看标题、列表、表格等内容；上方持续提示脚本、样式、交互控件和外部资源已省略。切到源码后仍可看到并编辑原始 HTML，返回预览会展示新正文的安全投影，不会用删减后的 HTML 覆盖源码。

空投影、加载、净化失败及预览超限分别显示恢复说明；完整源码始终保留。需要 CSS、脚本和应用交互时使用 owner 授权的开发预览。静态结构视图不充当开发环境运行验收，也不会自动执行“打开开发预览”的动作。


### 键盘与显式来源刷新

成果预览／源码／比较支持单一 Tab 入口、左右方向键及 Home／End，焦点与选中视图同步，RTL 方向反转；IME 组合事件和带修饰键的快捷键不被抢占。同一上下文的成果列表暂时变空后恢复，仍保留本地编辑。

Creator 正文引用可使用输入框既有“刷新来源→比较→取消／替换”：同一 ref 的当前版本须由 owner 明确发布，旧候选只重新授权自身，不自动跳到不同候选。取消保留改写，确认受草稿 revision 保护；proof id、权限或范围不符时保留草稿并拒绝替换。完整完成度和剩余依赖见 [逐项审计](../../openspec/changes/dsh-prompt-reference-creative-workspace-v1/completion-audit.md)。


### 图像查看与图表渲染

图片支持“查看图像／框选区域”切换。查看时可缩放、平移、旋转；返回框选时恢复正确坐标系，先前选区和批注保留。缩放倍率显式展示，图像工具文案随语言切换。

Mermaid 预览通过同一 profile 的现有 `dsh-mermaid-render` 插件渲染真实 SVG；安装步骤见 Creator bundle README。源码编辑后重新预览会更新节点和连线。节点文字采用 SVG text，图形样式净化后保留安全呈现属性；缺 renderer 的 profile 不算图形验收完成。


### 表格编辑与受限预览

CSV／TSV 使用首行作为列名，其余行作为数据，复用现有分页表格组件。带引号的分隔符和换行保持为单元格内容。非法引号显示首个错误字符位置，切回源码修正后恢复预览；超过行、列或单元格预览预算时明确说明只显示部分内容。完整源码不会被预览裁切或错误处理覆盖。

正文读取暂时失败时，可在当前 Pane 点击“重新读取正文”恢复；加载期间不会重复发起，也不会保存或清空其他草稿。若 owner 仍未授权，继续显示不可用状态。

实现增量：已挂载成果工作台的源码、预览及文本比较分别保存滚动状态；源码额外保留文字选区和方向。状态按工作区上下文、成果版本、视图及比较候选隔离，上下文改变即丢弃，恢复不改变键盘焦点。此临时状态当前不跨完整 Pane 卸载持久化；该剩余宿主能力继续在 task 4.1 跟踪。
