# 项目无限画布交互

状态：设计已确认，功能未实现。任务归 [画布 change](../../openspec/changes/dsh-project-canvas-continuity-v1/tasks.md)，执行语义归 [工作流 change](../../openspec/changes/dsh-creative-workflow-v1/tasks.md)。两者共用一个项目 document；本页不创建另一份 graph。

## 页面构成

```text
Pane 标题 / 项目定位（宿主管理）
┌────────────────────────────────────────────────────────────┐
│ 添加  选择  连线类型  搜索  撤销/重做  适配选区  运行范围    │
├───────────────────────────────────────────┬────────────────┤
│ 无限画布：素材 / 草稿 / 操作 / 成果 / 分组 │ 当前选区详情   │
│ 节点仅展示关键输入、参数、状态、选定结果    │ 参数或来源     │
│ 引用边 ≠ 执行边；媒体缩略预览按需加载      │ 打开专业 Pane  │
├───────────────────────────────────────────┴────────────────┤
│ 缩放比例 / 小地图 / 恢复提示（无第二运行或Target底栏）       │
└────────────────────────────────────────────────────────────┘
```

工具条在窄Pane折入菜单，执行动作由工作流能力提供。关闭画布不关闭原会话或取消运行。新增成果提示“查看/定位”，用户选择后才移动相机或打开Pane。

## 节点与控件

| 类型 | 节点内容 | 快捷操作 | 完整交互归属 |
|---|---|---|---|
| 素材 | 图片/视频/声音/文件/领域对象固定引用、来源和版本 | 预览、选区、加入明确会话、打开专业Pane | 原owner + 对应专业Pane |
| 文字草稿 | 可编辑便签或流程说明 | 编辑、复制、撤销 | 插件项目Draft；不冒充Auctra正文 |
| 操作步骤 | 主要输入、关键参数、费用/运行状态、选定结果 | 预览单节点运行、查看范围、打开专业Pane | 原owner/Ordo执行；工作流change负责入口 |
| 成果 | 固定候选/采用版本、媒体缩略图、receipt摘要 | 比较、选择版本、引用、打开专业Pane | 原owner候选/版本，不复制blob |
| 分组框 | 标题、包含节点、折叠状态 | 框选/分组/移动/折叠/解除分组 | 仅布局，不生成执行或权限边界 |

节点移动/缩放、分组、复制、撤销/重做只改变布局或未执行草稿。复制含owner引用的节点不复制资产；复制操作步骤只产生新草案，不重复发起旧run。草稿连接与执行连接有可辨认线型、端口和文字标签，不只靠颜色区分。

## 选择与专业 Pane

框选、多选、搜索结果、最小地图和键盘操作形成相同selection。媒体选区绑定资源版本、图片坐标或时间范围。加入会话先冻结project/session/ref/revision，复用已有prepare/ack；点击加入不发送。目标失效保留选择并要求重新选择，不改投全局current session。

专业Pane可并排、放大或独立打开；当前对象身份与画布一致，但放大/焦点由宿主负责。既有文本/媒体比较和候选采用复用成果工作区，不在节点内复制完整编辑器。

## 相机、搜索与媒体

固定使用 `@xyflow/react@12.11.6`。camera、selection和节点布局由可测试的状态转换管理，React Flow实例状态不直接作为持久schema。平移/滚轮缩放不劫持文本输入或Inspector滚动；支持fit selection、全图适配、回到当前运行节点、小地图和可访问对象列表。

缩略图按可见范围加载；离屏视频暂停，音频持续播放只在用户明确开启的专业试听Pane中存在。复杂媒体仅打开时加载。画布不扫描用户整个目录，素材由用户选择或授权owner列表进入。

## 持久化与冲突

host经批准的项目级storage保存document revision、相机、节点、分组、草稿和安全引用；不能把session storage字段重解释为project scope。schema由CLI/应用创建。保存采用revision条件，冲突保留本地草案并显示比较/重新应用路径；确认前显示pending，错误不显示saved。

打开项目先恢复已确认布局和有效引用，失权/过期引用显示状态；不执行Agent，不采用最新候选。用户上次的Pane选择、相机和领域内容事实分开恢复。Agent在授权范围内改布局/草稿时给出差异摘要并支持撤销，领域正文走owner candidate。

## 原型与验收

原型覆盖六类素材、五类节点、两类边、三种宽度和至少一个专业Pane并排。真实测试必须验证双栏session/project隔离、迟到结果、关闭重开、版本冲突、unknown零重试和无重复Target底栏。

性能用300个混合节点、包含图片/视频/音频缩略引用的固定样本，连续一小时记录输入p95、切换p95、拖拽帧、订阅/DOM/heap趋势和保存回执。指标与六件套证据见[公共方案](dsh-creative-studio-program.md)与[接口合同](../interfaces/dsh-creative-studio-contracts.md)。不得把fixture原型或未加载媒体的空白节点当真实可用验收。
