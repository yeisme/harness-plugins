# @yeisme/dsh-ai-drama-director

AI Drama Director Pack host and client units: current-context resolution, typed `/drama` handlers, snapshot+push events, Workbench handoff, Director preset, and redacted evidence.

```bash
pnpm --filter @yeisme/dsh-ai-drama-director run test
```

This package does not own show/episode state. Missing owner seams stay disabled. Official DSH decorate, CLI-authored bundle metadata, and live Workbench receipt paths stay out of this package.
