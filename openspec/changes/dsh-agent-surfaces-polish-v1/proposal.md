## Why

截图中的 Subagent 列表横跨整个会话、详情沉到底部，状态与操作缺乏层级。会话内子 Agent 与跨会话 Ordo 团队共用 Agents 名称，容易误认操作范围。

## What Changes

- 会话 Subagents Tab 使用紧凑执行树、状态筛选、搜索与同一区域内的对象详情，宽容器两列，窄容器切换。
- Agent Team 以本地用户工作区 Pane 为入口；列出明确注册的 Ordo 项目，再进入项目团队、计划、运行与现有任务图，不随聊天切换。
- 复用既有 owner 数据与动作；统一中英文、能力缺失说明、键盘焦点、空态和历史关联。

## Impact

归属 fit：交互与呈现归 Harness Plugins；split-owner：Ordo 保留团队、计划、批准与执行事实，DSH 保留子会话。本变更不启用上一变更尚未接线的真实执行器，不改旧协议、Pane kind 或项目引用。用户级指本机配置范围，不引入账号服务或跨租户权限。
