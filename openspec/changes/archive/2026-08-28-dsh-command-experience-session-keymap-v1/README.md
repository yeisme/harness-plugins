# dsh-command-experience-session-keymap-v1

Adds the `/session` management hub (switch / rename / archive / restore), stages `/archive` and `/delete` as preview-gated catalog entries, introduces the shared keyboard keymap (reducer cursor, Tab completion, Ctrl+K palette toggle) across Web and TUI, and lands the first formal `dsh-command-experience` capability spec (ADDED-only).

Artifacts: `proposal.md` (why/what/boundary), `design.md` (D1–D4 trade-offs), `tasks.md` (slices with validation), `specs/dsh-command-experience/spec.md` (requirements), `coverage-ledger.md` (P0/P1 + keymap table).
