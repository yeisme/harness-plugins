## 1. 定位反馈

定位必须先激活正确 session 和 Chat，再解析调用的稳定 owner 引用；禁止靠工具名、时间文本或全页文本搜索猜测记录。

- Pane：使用统一 accent 边框或顶部细线指示当前活动 Pane，保持浅色/深色主题均可见；离开该 Pane 后活动标记随焦点改变。
- 原调用行：定位成功后增加明确边框、低饱和背景和可访问的“已定位调用”反馈，不仅设置 DOM focus。
- 标记生命周期：最近一次成功定位的记录保持标记，直到下一次成功定位替换它、用户明确清除或视图卸载。失败定位不标记相邻行或其他会话的同名调用。不同视图的标记清理由工作台/Chat owner 管理，避免多个旧标记都被误认成当前目标。
- 连续定位同一记录再次滚动到目标并反馈成功；相同工具的两条调用必须按稳定身份区分。
- 折叠和历史加载：先由 Chat owner 加载、展开准确记录，再滚动；只展开定位所需范围，不能为定位一条调用永久展开整个会话。
- 滚动定位不得带动不相关 Pane 的滚动位置。尊重 reduced-motion；不使用持续闪烁或自动消失得过快的提示代替静态标记。
- 找不到原记录、会话不可访问、加载失败：保留当前详情并显示具体的安全原因，不伪造定位成功。

## 2. 执行命令 / 操作摘要

用户要求看见“原来调用什么命令”，不等于批准把整包 tool arguments、结果、脚本或秘密展示到详情。工具名仍保留，新增明确标为“执行命令 / 操作摘要（已脱敏）”的代码区。

摘要必须在拥有调用数据的 owner 层生成，经标准安全投影交给 Tools。ui-mcp-inspector 不直接解析 argsRaw、arguments、content 或原始 result 来拼 UI。优先复用已有公开、安全的调用呈现；若没有该能力，增加最小可选安全投影字段并保留旧记录兼容性。

建议最小语义：summary text、kind（command/operation）、redacted、truncated、缺失原因。具体 TypeScript 名称由实现时与已有 safe projection 合同对齐；这些字段是展示语义，不新增执行权限或调用参数通道。

- Shell：允许显示已审查的实际命令摘要，保留可辨认的可执行程序、子命令、普通参数和必要换行；禁止以工具名 bash 充当命令摘要。
- read/edit/write：显示操作类型与已授权的相对目标标识；不输出绝对私有路径、文件内容或 edit 的 old/new text。无法安全显示目标时只提供 owner 的可定位引用及缺失说明。
- 其他工具：仅显示该 owner 已定义的安全操作摘要；没有映射时诚实缺席，不序列化整个参数对象兜底。
- 保护凭据、认证头、Cookie、URL 内认证/敏感查询、环境变量值、令牌、私钥和秘密文件路径。不能只依靠一条敏感词正则宣称任意 Shell 已安全；未覆盖的参数形式默认不展示对应片段。
- heredoc、内联程序、多层 shell quoting、编码内容和子命令中的秘密无法可靠判断时，省略对应正文并解释原因，保留安全的执行类型或入口。
- 不把用户原始提示词、provider payload 或完整推理内容当作命令摘要。去除终端控制符及可误导阅读顺序的文本控制字符。
- 上限为600个显示字符；脱敏先于截断，避免截断后失去识别敏感字段的上下文。显式显示省略/截断状态，不伪装为完整原命令。
- 无摘要、旧记录或来源能力缺失时展示“没有安全摘要，可定位原消息”，而非空代码块或猜测命令。
- 本轮不增加重新执行、复制完整原始参数或自动重试入口。摘要不是可无条件再次执行的命令。

## 3. UI Contract

- Surface classification: adopted（Tools 内容）；原记录高亮为 embed；Pane 框架为宿主 owner。
- Surface kind: inspector，沿用 Diagnostics inspector。
- First / second / third visual priority: 当前定位/选择对象、执行摘要与结果、统计与辅助操作。
- Existing components reused: 既有 Surface、宿主按钮/Menu、代码呈现、列表/时间线及焦点管理。
- Cards that earn existence: 仅选中对象的详情边界；统计、导航和状态不再包大卡片。
- Primary scroll owner: 活动主列表；详情有界滚动。定位仅操作目标 Chat 的滚动容器。

视觉事实源：[统一视觉系统](../../../docs/design/dsh-unified-panel-visual-system.md)。仅消费现有 accent、border、surface、type、gap、radius token；不复制另一套主题或注入全局 reset。

标题不得被挤成单字或“工 / 目”等残片：为上下文标签保留可读最小宽度，必要时整项截断并提供 tooltip。低优先级统计可折叠成简短摘要；次级管理动作进入原生 More 菜单，不能把高风险或唯一恢复动作静默隐藏。“重新检测”不应独占一整行大按钮区。

活动/目录为一级选择，列表/时间线和状态筛选为紧凑次级控件。选中态覆盖整行（名称、状态、时间线所在行），使用低饱和背景加细 accent 边线，不只给工具名涂灰色矩形。失败、运行中与选中是不同语义，不能互相覆盖状态颜色和文字。

详情顺序：返回/关闭与工具名 → 执行摘要 → 状态、时间和耗时 → 安全错误说明 → 定位原消息。代码区可换行和横向查看长内容，但不能挤破 Pane；缺少摘要时用一条紧凑说明，不产生大面积空白。

时间线继续表达真实时间关系，不为让短调用看起来更长而伪造耗时。需要清楚的时间范围/刻度和分组说明；视觉最小条宽只是命中和可见性辅助，必须保留准确耗时文字。不可通过每行独立归一化把现有时间线悄悄变成另一种图。

### State Matrix

| 情形 | 呈现与行为 |
|---|---|
| 定位中 | 定位按钮pending，保留选择与详情 |
| 定位成功 | 目标Pane活动边界＋原调用持续标记＋可访问反馈 |
| 定位失败 | 安全原因，原详情保留，不标记错误对象 |
| 普通选中 | 列表/时间线整行一致选中，详情对应同一调用 |
| 有安全摘要 | 代码区展示摘要，明确脱敏与截断状态 |
| 无摘要/旧记录 | 原因说明与可用的定位入口，不读取原始参数兜底 |
| 窄屏/长标题 | 可读上下文优先，次级动作More，详情返回恢复原行 |

### Accessibility

键盘选行与鼠标选行产生相同的整行状态；定位成功后焦点落在目标记录的可操作锚点，反馈以可访问文字表达。返回详情列表恢复原选中行。状态不只靠颜色；reduced-motion 使用静态标记。200%缩放下功能保持可达。

### Visual Exceptions

无。任何宿主代码改动进入独立 upstream-prs 增量，不能把临时staging改动当作持久交付。
