# 实施任务（实施中）

文档阶段已交付 proposal、design、specs 和产品文档；用户随后授权按本 change 实施代码。下列复选框表示实际实施／验收，不表示文档是否已写完。文档就绪不等于功能完成，仅在对应证据成立后勾选。

依赖：第 1 组先完成；第 2 组建立文件／选区纵向链路；第 3 组依赖第 2 组；第 4 组依赖 1.3 与第 2 组；5.1–5.3 依赖 1.3、4.1，5.4–5.5 随相关组件完成；第 6 组针对稳定候选执行。外部 owner 缺口要登记操作、负责服务、所需交付物和受影响场景，不把缺失能力勾为已完成。
