## ADDED Requirements

### Requirement: 统一分组与安全结果身份
搜索呈现 SHALL 使用 owner 和稳定目标引用标识实体，将会话、面板与命令分组展示；不得仅凭同名去重。

#### Scenario: 面板与打开命令指向同一个目标
- **WHEN** 命令明确声明 open-only 且目标与面板相同
- **THEN** 默认列表只显示一个面板结果并保留原命令 ID 的可发现性
- **AND** 包含额外动作或仅名称相同的命令继续独立展示

#### Scenario: 空查询及兼容入口
- **WHEN** 用户打开搜索且没有关键词
- **THEN** 显示有界的最近使用、已打开和常用工具组，同一实体不重复
- **AND** 兼容入口默认折叠但通过精确名称或 ID 仍可发现

### Requirement: 筛选范围与计数诚实
搜索 SHALL 提供类别、项目、已打开和适用的状态／时间／插件筛选，使用可见条件标签并提供清除入口。

#### Scenario: 当前项目和全局工具
- **WHEN** 用户选择当前布局项目
- **THEN** 会话查询限定该项目，目录中的全局工具仍可发现
- **AND** 项目缺失时明确显示当前范围，不悄悄扩大已选择的范围

#### Scenario: Provider 不支持全量筛选
- **WHEN** 服务不能执行请求的时间或归档筛选
- **THEN** UI 明确显示该筛选不可用
- **AND** 不对第一页本地过滤后声称全部历史符合条件

#### Scenario: 结果仍在分页
- **WHEN** 来源只返回部分匹配结果且没有精确总数
- **THEN** 分组显示“已找到 N 项”及加载更多，不将该数量显示为完整总数

### Requirement: 确定排序与多语言匹配
搜索 SHALL 使用确定的匹配层级和稳定身份作为最终排序依据，安全高亮匹配内容。

#### Scenario: 中文和重复名称
- **WHEN** 输入中文子串、英文别名或代码标识符
- **THEN** 返回匹配结果并显示归属，精确匹配优先于低质量模糊匹配
- **AND** 高亮不将提供方文本解析成任意 HTML
