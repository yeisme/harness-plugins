# 宿主统一多 Pane 工作台

## 决策与边界

ui-layout 管理浏览器展示状态：分屏树、标签组、悬浮几何、焦点、预览／保留状态及按项目保存的布局。插件继续通过 slots 注册 UI，只提交布局意图，不拥有第二套窗口树。

SessionProvider 增加可选显式 sessionId，旧用法继续跟随全局选择。session-controller 的可选 present 方法仅打开官方历史呈现并持有视图 lease，不选择会话、不启动运行、不提交消息。内容 DOM 使用稳定兄弟节点，移动仅修改几何，避免丢失输入框与未保存编辑。

对话与轨迹使用同一个 session Pane，内部沿用官方视图选择；Agent preset chip 在已有会话下绑定明确 session，保留无会话时的旧 staged 选择流程。

## 兼容与恢复

旧 layout 服务和注册方式保留。完整宿主模式由 workspace.unified.v1 明确声明；下游适配器关闭旧 overlay 与插件布局持久化。布局记录只保存安全引用，不复制消息、草稿或凭据。旧布局由原 owner 解析并通过显式导入提交，原记录不删除，未知项目归属不自动推断。

拖拽以已提交快照为基线，使用指针捕获和实际坐标命中；取消、失焦、捕获丢失或并发变化放弃预览。缩放、触控和最小尺寸走同一几何投影。只在提交时保存，恢复不重放动作。

## 验证

Vitest 覆盖布局转换、重复会话拒绝、关闭保护、存储失败、显式会话绑定和旧接口兼容。联合浏览器验收覆盖真实鼠标／触控输入、四边分屏、跨组移动、浮窗、独立草稿、轨迹归属、预设与刷新、键盘和 HMR。离线历史由官方持久化服务生成，不调用模型。

本轮通过下游 upstream-prs 补丁通道交付，本地 staged runtime 保留全局已安装 DSH 作为回退；没有推送或发布。

## 自适应停靠增量

命中区按可用尺寸扩展，边缘选择保留小幅退出容差并允许更近边缘接管。拖拽捕获转移至稳定工作台根，避免预演标签跨组时丢失捕获。预演使用纯布局转换，已有内容保持稳定兄弟节点，侧栏新会话在松手前不挂载。

渲染根据可读宽度切换布局方向并约束首选比例，存储中的拓扑和比例不因窗口变化被覆盖。分隔线沿投影后的轴工作，双击可均衡。Alt 明确保留自由悬浮。
