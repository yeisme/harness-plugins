# 可编辑引用 ACK 按实例消费

顺序：composer-multi-reference-v1 → editable-prompt-references-v1 → editable-prompt-whitespace-v1 → 本补丁。用 `bash apply.sh <host-checkout>` 应用，两个先决文件的精确 hash 见 baseline.sha256。

提交时记录新模式的 Lexical 节点身份及正文／引用快照。ACK 后，原提交前缀未变仍用既有清理；某个引用已编辑时按稳定节点身份移除仍与提交快照一致的引用／文本叶，保留修改实例和新增文字。引用证明变化即使正文相同也不走整稿清空捷径。失败不进入消费，V1 保持旧路径。不用文件名／相同文本搜索删除用户新插入的对象。

本补丁针对实际 Host 中修改引用后已发送图片仍残留的回归，23 项提交／生命周期测试通过。真实 Host 的 ACK 响应延迟测试验证引用数从 2 降到 1、修改内容和新文字保留、冻结消息／模型内容不变。

补充回归：ACK 等待期间将引用替换为正文相同的新节点，或仅更新版本／摘要／来源证明而保持正文不变，旧提交均不得消费这些新状态。两种情况与既有提交／生命周期测试共 23 项通过。

另验证发送期间追加同一对象的同文新实例：成功 ACK 仅移除原提交实例，新实例保留。失败分支等待真实错误通知再断言草稿保留，避免在结算前取得假阳性。
